# `rustcode acp` — ACP Agent 模式实施方案

> **致 agentic worker：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 来逐任务实施本计划。步骤使用复选框（`- [ ]`）语法跟踪进度。

**目标：** 新增 `rustcode acp` 子命令，让 rustcode 以 Agent Client Protocol（ACP）agent 的身份通过 stdio 运行，使编辑器/编排器（例如 Zed）可以把它当作多 agent 团队中的一个 agent 来驱动。

**架构：** 新建 crate `rustcode-acp`，用 `agent-client-protocol` 1.0.1 的 builder API 构造 ACP agent，并通过 `Stdio` 提供服务。每个 ACP session 都通过 `rustcode-coding` 的 `prepare → assemble → spawn` 跑一个 kernel 原生的 rustcode agent，再把 kernel 的 `AgentEvent` 翻译成 ACP `session/update` 通知，并把 kernel 的审批 `Request` 路由到 ACP `session/request_permission`。CLI 新增 `Acp` 命令，调用 `rustcode_acp::serve_stdio`。

**技术栈：** Rust、tokio、`agent-client-protocol = "=1.0.1"`（及其 `schema::v1` 类型）、`rustcode-kernel`、`rustcode-coding`、`rustcode-capabilities`、`serde_json`。

## 全局约束

- 用 `CARGO_INCREMENTAL=0` 按包构建 —— 绝不构建整个工作区（磁盘接近写满）。示例：`CARGO_INCREMENTAL=0 cargo test -p rustcode-acp`。
- `agent-client-protocol` 1.0.1 是 **edition 2024 + 原生 async 闭包** → 工具链必须 ≥ 1.85（在任务 1 中验证）。`rustcode-acp` 自身保持 `edition = "2021"`。
- 把依赖固定为 `=1.0.1`（该 crate 很新，避免 API 变动）。
- **stdout 专供 ACP JSON-RPC 流使用，不得挪作他用。** `rustcode-acp` 内、以及 `rustcode acp` 代码路径上的任何位置都不得出现 `println!` / `print!`。所有诊断信息只走 `eprintln!`（stderr）。这是每个任务都要过的评审闸门。
- `agent_client_protocol::schema::v1` 下几乎所有类型都是 `#[non_exhaustive]` —— 一律通过它们的 `::new(...)` builder 构造，绝不要写结构体字面量。
- 互操作目标：对外声明 `ProtocolVersion::V1`。

### 试点（任务 1）必须解决的已知未知项

以下外部 crate 行为尚未确认；任务 1 负责把它们确认下来，后续任务据此适配：

1. **handler 的确切用法**：`responder.respond(...)` 的精确签名、`cx.send_request(req).await` 如何产出带类型的响应，以及 `on_receive_request!()` 宏参数的确切形式。下面那段逐字照搬的示例是起点。

```rust
use agent_client_protocol::schema::v1::{
    AgentCapabilities, InitializeRequest, InitializeResponse, PromptCapabilities,
};
use agent_client_protocol::{Agent, Client, ConnectionTo, Dispatch, Stdio};

#[derive(Debug, Clone, Default)]
pub struct AcpServeOptions {
    pub provider: Option<String>,
    pub model: Option<String>,
}

pub async fn serve_stdio(_opts: AcpServeOptions) -> anyhow::Result<()> {
    Agent
        .builder()
        .name("rustcode")
        .on_receive_request(
            async move |init: InitializeRequest, responder, _cx| {
                responder.respond(
                    InitializeResponse::new(init.protocol_version)
                        .agent_capabilities(
                            AgentCapabilities::new()
                                .load_session(false)
                                .prompt_capabilities(PromptCapabilities::new().image(true)),
                        ),
                )
            },
            agent_client_protocol::on_receive_request!(),
        )
        .on_receive_dispatch(
            async move |message: Dispatch, cx: ConnectionTo<Client>| {
                message.respond_with_error(
                    agent_client_protocol::util::internal_error("unhandled message"),
                    cx,
                )
            },
            agent_client_protocol::on_receive_dispatch!(),
        )
        .connect_to(Stdio::new())
        .await
        .map_err(|e| anyhow::anyhow!("acp serve failed: {e}"))
}
```

```rust
    ToolCall as AcpToolCall, ToolCallId, ToolCallStatus, ToolCallUpdate, ToolCallUpdateFields, ToolKind,

pub fn tool_kind(name: &str) -> ToolKind {
    let n = name.to_ascii_lowercase();
    if n.contains("read") || n.contains("cat") { ToolKind::Read }
    else if n.contains("edit") || n.contains("write") || n.contains("replace") || n.contains("apply") { ToolKind::Edit }
    else if n.contains("delete") || n.contains("rm") { ToolKind::Delete }
    else if n.contains("move") || n.contains("mv") || n.contains("rename") { ToolKind::Move }
    else if n.contains("grep") || n.contains("search") || n.contains("glob") || n.contains("find") { ToolKind::Search }
    else if n.contains("fetch") || n.contains("http") || n.contains("web") { ToolKind::Fetch }
    else if n.contains("bash") || n.contains("shell") || n.contains("exec") || n.contains("run") { ToolKind::Execute }
    else { ToolKind::Other }
}
```

```rust
use agent_client_protocol::schema::v1::StopReason as AcpStop;
use rustcode_kernel::event::StopReason as KStop;

pub fn stop_reason(r: KStop) -> Result<AcpStop, &'static str> {
    match r {
        KStop::Stopped => Ok(AcpStop::EndTurn),
        KStop::MaxRounds | KStop::MaxContinuations => Ok(AcpStop::MaxTurnRequests),
        KStop::Cancelled => Ok(AcpStop::Cancelled),
        KStop::PromptRejected => Ok(AcpStop::Refusal),
        KStop::ProviderError => Err("provider error"),
        KStop::Timeout => Err("turn timed out"),
        KStop::RateLimited => Err("rate limited"),
        _ => Err("turn ended abnormally"),
    }
}
```

```rust
use std::path::PathBuf;
use std::sync::Arc;
use rustcode_coding::config::CodingAgentConfig;
use rustcode_coding::parts::{assemble, prepare, PrepareOptions, SessionMode};
use rustcode_kernel::agent::AgentHandle;
use rustcode_kernel::provider::LlmProvider;

#[derive(Debug, Clone)]
pub struct EngineConfig {
    pub api_key: String,
    pub base_url: String,
    pub model: String,
    pub provider_type: String,
    pub context_window: u32,
    pub max_tokens: Option<u32>,
}

impl EngineConfig {
    pub fn to_coding_config(&self, cwd: PathBuf) -> CodingAgentConfig {
        let mut cfg = CodingAgentConfig::new(&self.api_key, &self.base_url, &self.model, cwd);
        cfg.context_window = self.context_window;
        cfg.chat_options.max_tokens = self.max_tokens;
        cfg.provider_type = self.provider_type.clone();
        // ACP sessions are long-lived & interactive: no per-request hard timeout.
        cfg.request_timeout = None;
        cfg
    }
}
```

```rust
pub async fn handle_new_session(
    engine: &EngineConfig,
    provider: Option<Arc<dyn LlmProvider>>,
    sessions: &Sessions,
    counter: &std::sync::atomic::AtomicU64,
    req: NewSessionRequest,

    let id = new_session_id(n);

    Ok(NewSessionResponse::new(id))
}
```

```rust
use agent_client_protocol::schema::v1::{
    PermissionOption, PermissionOptionId, PermissionOptionKind as Kind,
    RequestPermissionRequest, RequestPermissionOutcome, SessionId, ToolCallId, ToolCallUpdate,
    ToolCallUpdateFields,
};
use rustcode_kernel::event::AgentCommand;
use tokio::sync::mpsc::UnboundedSender;

pub fn permission_options() -> Vec<PermissionOption> {
    vec![
        PermissionOption::new("allow_once", "Allow once", Kind::AllowOnce),
        PermissionOption::new("allow_always", "Always allow", Kind::AllowAlways),
        PermissionOption::new("reject_once", "Reject once", Kind::RejectOnce),
        PermissionOption::new("reject_always", "Always reject", Kind::RejectAlways),
    ]
}

pub fn outcome_to_decision(option_id: &str) -> serde_json::Value {
    match option_id {
        "allow_once" => serde_json::json!({"decision": "allow"}),
        "allow_always" => serde_json::json!({"decision": "allow", "remember": true}),
        _ => serde_json::json!({"decision": "deny"}), // reject_* and anything unknown
    }
}

pub async fn handle_approval(
    cx: &agent_client_protocol::ConnectionTo<agent_client_protocol::Client>,
    session_id: &SessionId,
    cmd_tx: &UnboundedSender<AgentCommand>,
    req_id: u64,
    payload: serde_json::Value,
) -> Result<(), agent_client_protocol::Error> {
    let tool = payload.get("tool").and_then(|v| v.as_str()).unwrap_or("tool").to_string();
    let call_id = payload.get("call_id").and_then(|v| v.as_str()).unwrap_or("").to_string();
    let tc = ToolCallUpdate::new(
        ToolCallId::new(call_id),
        ToolCallUpdateFields { title: Some(tool), ..Default::default() },
    );
    let resp = cx
        .send_request(RequestPermissionRequest::new(session_id.clone(), tc, permission_options()))
        .await?;
    let decision = match resp.outcome {
        RequestPermissionOutcome::Selected(sel) => outcome_to_decision(sel.option_id.0.as_ref()),
        _ => serde_json::json!({"decision": "deny"}), // Cancelled → fail closed
    };
    cmd_tx.send(AgentCommand::Respond { id: req_id, value: decision }).ok();
    Ok(())
}
```
