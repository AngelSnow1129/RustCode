# T1：修正 `.codebuddy/agents/*.md` 中过时的 crate 名

## 1. 背景与问题

仓库已完成 `atomcode-*` → `rustcode-*` 的产品重命名（crates、二进制、配置目录 `~/.rustcode`、
环境变量 `RUSTCODE_*`）。此前 `.codebuddy/` 被 `.gitignore` 排除，2026-09-03 起纳入版本控制、
随仓库共享，从而使以下问题首次产生后果：`.codebuddy/agents/*.md` 中仍写着旧 crate 名，
而这些文件是子 Agent 被调度时加载的系统提示，子 Agent 会据此执行 `cargo -p atomcode-tuix` 之类命令，
必然失败（实测 `error: package ID specification 'atomcode-*' did not match any packages`）。
