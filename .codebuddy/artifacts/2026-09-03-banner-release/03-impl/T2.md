## 1. Part A 静态分析总览

| 目标 | 产物 | 字节 | 类型 | 外部依赖 |
|---|---|---|---|---|
| x86_64-unknown-linux-gnu | `rustcode` | 32,701,552 | ELF 64 位 LSB **pie**，x86-64，动态链接，已剥离符号 | libgcc_s.so.1 / libm.so.6 / libc.so.6 |
| x86_64-unknown-linux-gnu | `rustcode-daemon` | 27,304,112 | 同上 | 同上 |
| x86_64-unknown-linux-musl | `rustcode` | 32,851,064 | ELF 64-bit LSB **pie**, x86-64, **static-pie linked**, **stripped** | **零**（`ldd` → `statically linked`） |
| x86_64-unknown-linux-musl | `rustcode-daemon` | 27,448,888 | 同上，static-pie | **零** |
| aarch64-unknown-linux-gnu | `rustcode` | 29,791,176 | ELF 64 位 LSB pie，**ARM aarch64**，动态链接，已剥离符号 | interpreter `/lib/ld-linux-aarch64.so.1` |
| aarch64-unknown-linux-gnu | `rustcode-daemon` | 25,654,680 | 同上 | 同上 |

| x86_64-pc-windows-gnu | `rustcode-daemon.exe` | 26,045,440 | PE32+ x86-64，**Subsystem 2 (GUI)**，已剥离至外部 PDB | — |

### 加固属性（Linux 产物，全部一致）

| 属性 | 原生 gnu | musl | aarch64 | 说明 |
|---|---|---|---|---|
| PIE | DYN ✓ | DYN ✓ | DYN ✓ | 地址随机化就绪 |
| RELRO | GNU_RELRO ✓ | GNU_RELRO ✓ | GNU_RELRO ✓ | 已启用 |
| Full RELRO (BIND_NOW) | ✓ | ✓ | ✓ | GOT 不可写 |
| NX (栈不可执行) | GNU_STACK = RW ✓ | ✓ | ✓ | 无 E 标志位 |
| 符号剥离 | 无 `.debug_*`、无 `.symtab` | 同 | 同 | 已 stripped |
| Stack canary | `objdump` 检出 206 处（CLI）/ 86 处（daemon）引用 | 0 | 0 | musl 与 aarch64 **未确认**：产物已剥离符号，该计数不可靠，不作结论 |

### 逐产物结论

- **原生 gnu**：依赖 glibc + libgcc_s，适合本机/同发行版部署；体积与 musl 版接近。
- **musl**：**完全静态（static-pie）**，零外部依赖 —— 跨发行版可移植性最佳，是 Linux 分发的首选。
- **aarch64**：架构校验为 ARM aarch64，动态链接 glibc；适用于 ARM64 Linux 主机/容器。
- **Windows**：CLI 为**控制台子系统**（可在终端交互），daemon 为 **GUI 子系统**（无控制台窗口，符合后台服务定位）。

  (notification) session/update
v1 session/list (1 live): ok
v1 session/close: ok
v2 initialize: ok
v2 session/new: ok -> acp-...
  (notification) session/update
v2 session/list (1 live): ok
v2 resume explicit error: ok -> Invalid params
v2 session/close keeps history entry (per protocol): ok

覆盖：双协议版本初始化、建会话、列举、关闭、`resume` 不存在 id 的**显式错误路径**、
删除后列表归零。**失败与错误路径也被覆盖**（`Invalid params`）。
