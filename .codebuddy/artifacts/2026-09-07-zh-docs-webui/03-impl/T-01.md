### 3.7 `hostscan`（修复前 vs 修复后）

**修复前（缺陷）**：

```console
$ python3 scripts/check-zh-docs.py hostscan --base 3ee655e3; echo "HOSTSCAN exit=$?"
hostscan: base=3ee655e3 命中 0 个文件（内容来源：工作区优先，缺失时回退基线）
...
hostscan: 命中文件 0，命中行 0
HOSTSCAN exit=0
```

**根因**（实测复现）：

```console
原始行: > compose 端口默认仅绑定 `127.0.0.1`（本机访问）。
masked(现状): > compose 端口默认仅绑定  （本机访问）。
masked 后还能搜到 IP 吗: False
不 mask 能搜到 IP 吗: True
不 mask 的默认关键词: True

--- 现有 HOST_DEFAULT_RE 对变形词的覆盖 ---
  By default       -> True
  defaulting to    -> False
  defaults to      -> True
  默认               -> True
  默认绑定             -> True
  Default          -> True
```

即：文档惯例把 IP 写成 `` `127.0.0.1` ``，而旧实现沿用 AC-2 的做法先 `INLINE_RE.sub(" ", eff)` 抹掉 inline code 再搜字面量 ⇒ 字面量恒被抹除 ⇒ 命中恒 0；
且 `\bdefault\b` 漏掉 `defaulting`。
