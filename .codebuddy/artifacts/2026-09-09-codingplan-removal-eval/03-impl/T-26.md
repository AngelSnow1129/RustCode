## 5. 遗留风险与后续项

1. **`/login` 语义已变（需文档同步）**：原 `/login` = 登录 + `POST /codingplan/setup` + 回贴 `report_text`；现为纯登录 + 一条状态文案。这是 Q5「一并清理」的必然后果（路由已删），已按 N-4 保留登录门控本身，但**功能上不再产生 Provider**。建议由 **T-30（docs）+ T-29（AGENTS.md）** 同步口径；本任务不得改 `docs/`。
2. **`requires_login` 未清理（明确登记，不硬删）**：`01-design.md` §9 把 `ProviderInfo.requires_login` 列为 wire 契约变更并要求「扩展同批清理」，但 `02-tasks.md:389` 的 T-26 改动摘要**未**列入该项，且它不是 `codingplan` 字面量（不影响 AC-11）。扩展侧现存 7 处：`src/chat/provider.ts:1887`、`src/daemon/types.ts:154`、`webview-ui/src/components/ModelSelector.tsx:56`、`webview-ui/src/state/reducer.ts:34/36/38`、`webview-ui/src/state/types.ts:42`。这些是**活跃代码分支**（影响模型选择器的「需登录」判定），删除会改变运行时行为。**建议负责人：T-18 owner（daemon wire DTO）与编排者定夺**，或单列任务。
3. **欢迎页「模型」步骤退化为纯文案**：同步按钮移除后，托管构建下用户只能走「手动添加 Provider」。已把 `setup.syncOrAddProvider` 文案改为引导手动添加，但 UI 上该步骤不再有任何操作入口。是否需要补偿入口（如直接展开 Provider 表单）属产品决策，**建议：编排者 / solution-architect**。
4. **两条新增 l10n 文案只有中文**：仓库不存在 `l10n/bundle.l10n.json`（en bundle），en 由 `vscode.l10n.t` 内联英文默认串兜底，与既有做法一致（如 `Signed out.`）。
5. **未跑 `npm run lint`**：`package.json` 有 `lint` script 但 `devDependencies` 未声明 `eslint`，运行必然失败；且 lint 不在 T-26 验证清单内。**未执行**，不作为验证证据。
6. **环境副作用**：为获取基线在 `extensions/vscode/` 下执行了 `npm ci`（生成 `node_modules/`，已被 `.gitignore` 忽略）与 `npm run build:webview`（生成 `webview/webview.js|.css|.map`，已被根 `.gitignore:117-120` 忽略）。两者**均不进 git**。
