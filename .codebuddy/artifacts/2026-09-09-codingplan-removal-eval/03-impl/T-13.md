# T-13'（= T-13 + T-14 + T-15 合并）tuix 侧 codingplan 消费点整体剥离

> P3 轮，单 Agent。本文件在实现过程中先落骨架、后补结论。

## 0. 改动计划（落盘时点：改代码之前）

> **接续说明（第二轮，接手时工作区编译红）**：前任 Agent 已完成 1、2 与 3 的**主体**（`lib.rs`
> / `state.rs` / `event_loop/commands.rs` 的函数级删除），但 `event_loop/mod.rs` **完全未动**，
> 导致 `LoopCtx` 五字段、`footer_usage` 读取点、`UsageData`/`UsageModal` 测试引用全部悬空。
> 本轮的落地顺序因此调整为「**先补齐 `event_loop/mod.rs` 使其转绿**，再回头把 `commands.rs`
> 剩余的 cfg 门控块与注释清干净」。

1. `lib.rs`：删测试 ctor 中的 `RUSTCODE_CODINGPLAN_LLM_BASE_URL` env、删 `LoopCtx` 五个
   codingplan 字段的初始化、删启动漂移检查块。**（前任已完成，本轮复核无残留）**
2. `state.rs`：删 `footer_usage` 字段与其读写点、删 `sample_usage_panel()` 夹具与依赖它的用例。
   **（前任已完成，本轮复核无残留）**
3. `event_loop/commands.rs`：删 `fetch_usage_data()` 两变体；`open_usage()` 退化为恒渲染
   `Msg::UsageCodingPlanOnly`；删 17 处 `#[cfg(feature="codingplan")]` 块（保留 neutral 孪生并去 cfg）；
   删 `footer_usage` 读写点；删 `use crate::modals::usage::{UsageData, UsageModal}`；注释中立化。
   **（前任已完成 60%，本轮补齐：QR/login chrome 四个 cfg 函数 + 两个 cfg 测试模块 +
   `run_oauth_with_renderer` / `run_coding_plan_blocking` / cfg 版 `run_login_flow` +
   `streaming_usage_snapshot_composes_plan_and_window_lines` 用例 + 全部注释）**
4. `event_loop/mod.rs`：**本轮主战场**。删 `LoopCtx` 五个字段与全部读写点；删
   `handle_footer_usage_tab_key` 与其 5 个用例 + `empty_usage_panel()` 夹具；删 `needs_official_build`
   分支；删 `apply_persisted_config`（cfg 块）；删 `refresh_after_cross_process_codingplan_sync`；
   删启动 / 提交前 / TurnComplete 后三处 monitor+usage_monitor 触发；删
   `RUSTCODE_CODINGPLAN_REPORT` env 交接；删 `mod monitor;` / `mod usage_monitor;` 声明；
   顺带删 `provider_requires_codingplan_auth` 及其三个消费点（**说明见 §5 R-1：属 T-19 面，
   因 T-14 删 env 已使其恒为 false 且轮末 grep 要求 `event_loop/mod.rs` 归零而一并处理**）；
   注释中立化。
5. `commands.rs`：`login` / `usage` 静态描述改中性文案。
6. `render/*`、`sanitize.rs`、`event_loop/oauth_poll.rs`：注释中立化（无行为改动）。
