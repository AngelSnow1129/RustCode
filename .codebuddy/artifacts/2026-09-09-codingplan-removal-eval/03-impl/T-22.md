# T-22 —— coding crate 去 ProviderAuthenticator

## 1. P6 已处理了什么

- 删除 L2 签名层：`auth::gateway_crypto`、`capabilities::codingplan_sign`、桩 crate
  `rustcode-codingplan-crypto`（这两个文件的删除属于 P6，不在本次改动内，见 `git diff --stat`）。
- P6 清掉了 **具体实现** `CodingPlanProviderAuthenticator` 的引用，但 **trait 本身还留在 coding crate**：
  `provider_factory.rs` 仍定义并导出 `pub trait ProviderAuthenticator`，`DefaultCodingProviderFactory`
  仍持有 `authenticator` 字段与 `with_authenticator()` 构造器，`lib.rs` 仍 re-export。

## 2. 本轮收尾改了什么

### 2.1 删除 `ProviderAuthenticator` 接缝（功能性）

| 位置 | 变更 |
| --- | --- |
| `crates/rustcode-coding/src/provider_factory.rs:1-7` | import 去掉 `RequestSigner`（随接缝一起失效） |
| `crates/rustcode-coding/src/provider_factory.rs:34-42`（原） | 删除 `pub trait ProviderAuthenticator` 定义 |
| `crates/rustcode-coding/src/provider_factory.rs:52-70`（原） | `DefaultCodingProviderFactory` 删除 `authenticator` 字段；删除 `with_authenticator()` |
| `crates/rustcode-coding/src/provider_factory.rs:179-183`（原） | OpenAI-compat 分支删除 `pc.request_signer = authenticator.request_signer(...)` 赋值 |
| `crates/rustcode-coding/src/lib.rs:86` | re-export 去掉 `ProviderAuthenticator` |

保留项（**不是** CodingPlan 残留，仍是活代码）：
- `ProviderBuildError::Authentication` 与 `ProviderBuildError::SourceBuildGatewayUnsupported`
  是 `CodingProviderFactory` 的通用错误变体，`runtime.rs:2001/2009` 生产代码消费，
  `runtime.rs:8352/8370/11818` 测试构造/断言，删除会导致 `/goal` 与恢复路径失效，故保留。
- `OpenAiCompatConfig::request_signer`（capabilities 层）保持原样，coding 层只是不再设置它。

### 2.2 `CodingPlan` 表述中立化（纯注释/文档，无行为变更）

其余 30 余处命中全部是围绕"网关配额窗口"的注释，`rate_limit.rs` 的机制本身是 host 注入的
`RateLimitWindowSource` + `applies_to` 门禁，与具体网关产品无关，因此改为中性表述
（"CodingPlan 网关" → "source 适用的 endpoint / managed endpoint"，"CodingPlan quota" → "quota / plan quota"，
"non-CodingPlan" → "no quota data / unmanaged endpoint"）。

- `crates/rustcode-coding/src/rate_limit.rs`：模块头、`RateLimitWindow` / `RateLimitWindowSource` /
  `RateLimitHook` 文档、`on_rate_limit` 门禁注释、`Default` 与 3 处测试注释。
- `crates/rustcode-coding/src/config.rs:625,631-632,643,661,857,915`：`/goal` 轮次预算相关注释。
- `crates/rustcode-coding/src/parts.rs:1048-1052,1184,1697-1700`：`RateLimitHook` 构建位置与
  `rate_limit_source()` 文档。
- `crates/rustcode-coding/src/provider_factory.rs:169-170`、`persona.rs:114`、
  `skill_first.rs:18`、`runtime.rs:7897`：各 1 处措辞。
