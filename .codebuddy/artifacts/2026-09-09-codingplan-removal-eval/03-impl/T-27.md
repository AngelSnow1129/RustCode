### 3.5 i18n 键 parity（对应 `02-tasks.md:406-415` 验证 1）

以 `RustCodeBundle.message(<locale>, "key")` / `message("key")` 首参字面量为准（原脚本的 `%key` 正则对 Kotlin 无效，此处改为提取真实调用点）：

```
$ cd /workspace/RustCode && python3 -c "
import re,pathlib
base=pathlib.Path('extensions/jetbrains/src/main')
kt='\n'.join(p.read_text() for p in base.rglob('*.kt'))
xml='\n'.join(p.read_text() for p in (base/'resources').rglob('*.xml'))
src=kt+xml
used=set(re.findall(r'RustCodeBundle\.message\(\s*(?:locale|[A-Za-z_][\w.]*)\s*,\s*\"([A-Za-z0-9_.]+)\"',src))
used|=set(re.findall(r'RustCodeBundle\.message\(\"([A-Za-z0-9_.]+)\"',src))
used|=set(re.findall(r'\"%([A-Za-z0-9_.]+)\"',src))
for f in ['RustCodeBundle.properties','RustCodeBundle_zh.properties']:
    keys=[l.split('=')[0].strip() for l in (base/'resources/messages'/f).read_text().splitlines() if l.strip() and not l.startswith('#')]
    ks=set(keys)
    print(f,'keys=',len(ks),'dup=',len(keys)-len(ks))
    print('  MISSING(used but not defined):',sorted(used-ks))
    print('  UNUSED(defined but not referenced):',sorted(ks-used))
"
RustCodeBundle.properties keys= 211 dup= 0
  MISSING(used but not defined): ['.1fs', '20']
  UNUSED(defined but not referenced): ['chat.setupFailed', 'chat.setupReport']

  UNUSED(defined but not referenced): ['chat.setupFailed', 'chat.setupReport']
```
